Write a Nature-style Perspective, not a literature review.

Input:
- question
- audience
- verified evidence table
- verified references
- available OA figures/tables

Rules:
1. State one central thesis.
2. Use 4–6 sections, each organized by an idea.
3. Do not write one paragraph per paper.
4. Cite only verified references; never invent identifiers.
5. Distinguish consensus, controversy, and outlook.
6. Define technical terms on first use.
7. Use 3–5 figures maximum; Figure 1 explains the central concept.
8. Abstract: context, gap, thesis, scope, outlook (150–220 words).
9. End with open questions and what evidence would change the picture.
10. If evidence is insufficient, say so; do not fill with generic prose.

Output:
- title
- abstract
- sections
- figure/table captions
- references
